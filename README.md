# 🛒 E-Commerce SQL Database & Business Reports

## 📌 Project Overview

This project is an **E-Commerce Database Management System** developed using **MySQL**.

The project demonstrates how SQL can be used to manage customers, products, orders, order items, and payments, as well as generate useful **business reports and sales insights**.

The database contains multiple related tables connected using **Primary Keys and Foreign Keys**.
